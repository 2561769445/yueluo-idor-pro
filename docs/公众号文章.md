# 🌙 月落：我把越权测试做成了"登录一次，报告自己出来"

> 越权漏洞是 OWASP Top 1，但 90% 的团队在用最原始的方式测它。

## 一、越权测试为什么这么累？

如果你做过越权测试，这个流程一定很熟悉：

1. 开两个浏览器，分别登录账号 A 和账号 B
2. 用 A 操作一遍所有功能，抓包记录
3. 把 A 的请求拿出来，换成 B 的 Cookie 重放
4. 对比响应，判断 B 能不能看到 A 的数据
5. 换个接口，重复第 3-4 步……几百次

一个中等规模的系统，几百个接口，两个人测一天未必能全覆盖。而且最难的不是累，是**漏**——你没用到的功能点、藏在 JS 里的隐藏接口、忘了测的 HTTP 方法，每一个都可能藏着一个 P0。

更糟的是测完之后：几百条对比结果里，一半是时间戳差异、公共字典接口这类"假越权"，误报筛查又是一下午。

**我们把这整套方法论，做成了一个自动化工具：月落。**

## 二、月落是怎么工作的

整个流程只需要你做一件事：**登录**（有验证码的系统正好，人工输）。

```
添加账号A/B/C → 工具弹出3个独立浏览器 → 各自登录
    ↓
🕸 自动遍历：自动收集页面路由逐个导航 + 从API前缀枚举常见子端点
   （实测：13条手动录制 → 自动遍历后390条，测试面扩大10倍）
    ↓
⚔️ 六重测试引擎交叉重放
    ↓
判定分级（五层降噪）→ 🤖 AI复核误报 → 📊 导出报告
```

### 六重测试引擎，每一重瞄准一个越权成因

| 引擎 | 检测什么 |
|------|---------|
| **cross 换凭证** | B 的凭证访问 A 的请求——服务端到底校不校验凭证归属？ |
| **noauth 去凭证** | 不带任何登录态裸访问——未授权访问直接现形 |
| **param_swap ID 交叉** | A 的凭证 + B 的 ID = B 的数据？这是水平越权的铁证 |
| **深度验证·XFF** | 有些接口看着"防护正常"，伪造个内网头就穿了 |
| **深度验证·方法翻转** | GET 有鉴权 POST 没有？方法级差异一测便知 |
| **baseline 基线** | 原样重放，排除防重放机制干扰 |

### 五层降噪，高危即高可信

自动判定最大的敌人是误报。月落内置五层降噪：

- 时间戳/流水号字段自动忽略
- 公共接口识别（双方本来都能访问的）
- "按身份返回"识别（返回的是重放者自己的数据=正常）
- 公开数据不报未授权
- 登录/验证码类接口自动排除

在包含 9 类典型场景的本地靶场上，**高危检出 100% 命中、零误报**（源码仓库自带靶场，你可以自己验证）。

### AI 复核：最后一公里

自动化判定再准，总有模糊地带（加密响应、非常规业务语义）。月落支持接入任何 OpenAI 兼容的大模型（智谱/OpenAI/自建网关），一键让 AI 逐条复核全部疑似项：

- ✅ **AI确认** —— 真漏洞
- ❌ **AI误报** —— 可以放心删
- 👤 **AI待人工** —— 数据不足，留给人

实测一轮几百条疑似项，AI 筛完只剩真正需要人看的十来条。

## 三、几个设计细节

**1. 人工操作完整保留。** 自动遍历是叠加不是替代——重点业务流程（审批链、支付流）还是要人工走，工具负责把菜单里的冷门接口补全。两边录制自动去重，不会重复测试。

**2. 删除类操作默认跳过。** 工具再快也不能帮你把客户数据删了。DELETE 方法、URL 带 delete/remove 语义的请求一律跳过并记录在案。更保守的场景可以一键切换"仅测 GET"。

**3. 数据包左右对照。** 每条结果点开详情：左边请求包、右边响应包，上面原始流量、下面越权重放流量——四象限对照，是不是漏洞一眼可辨，报告可直接截图。

**4. Burp 联动。** 填上 127.0.0.1:8080，全部重放流量经 Burp 留档，报告可直接引用 Burp History 编号。

**5. 单文件 exe。** 13MB，Python 解释器和全部依赖都打包在内。发给同事一个文件，双击就能用——只要机器上有 Chrome 或 Edge（Win10/11 自带）。

## 四、什么场景适合用

- **研发团队上线前自测**——把访问控制问题挡在上线前
- **渗透测试项目**——授权测试中快速摸清全部接口的鉴权状况，高危结果直接进报告
- **等保/合规检查**——自动化产出可复核的证据链
- **多角色系统**（ERP/OA/CRM/医疗/政务）——管理员+普通用户组合，水平垂直一起测
- **权限模块重构后的回归**——不依赖文档，录制池说了算
- **老系统梳理**——接口多文档缺，自动遍历把隐藏接口全扫出来
