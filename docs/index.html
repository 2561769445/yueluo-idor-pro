六重测试引擎

每一重都瞄准越权的一个独立成因

1baseline 原样重放

录制有效性验证 + 防重放机制检测，排除干扰项

2cross 换凭证重放

用 B 的凭证重放 A 的请求 —— 检测服务端是否校验凭证归属（水平/垂直越权）

3noauth 去凭证重放

去掉全部 Cookie/Token 裸请求 —— 检测未授权访问

4param_swap ID 交叉

A 的凭证 + B 的 ID 参数 = B 的数据？铁证级水平越权证据

5深度验证 · 请求头变体

对"防护正常"的接口追加 XFF 伪造复核 —— 部分系统的防护一戳就穿

6深度验证 · 方法翻转

GET↔POST 同 URL 复核 —— HTTP 方法级鉴权不一致检测

判定分级 · 五层降噪

时间戳噪声 / 公共接口 / 按身份返回 / 公开数据 / 认证接口 自动排除，高危即高可信

🔴 高危 · 附复现步骤与影响说明
🟡 中危 · 需人工确认项
🟢 正常 · 服务端正确拒绝
⚪ 公共 · 自动降噪
