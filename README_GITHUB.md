## 📖 简介

越权漏洞（Broken Access Control）是 OWASP Top 1 的安全风险，但手工测试需要多账号逐接口对比、工作量巨大且容易遗漏。

**月落**把这套方法论自动化了：

> 配置多个账号 → 工具弹出多个独立浏览器 → 各自登录后自动遍历系统接口 → 一键交叉重放（换凭证 / 去凭证 / 换ID）→ 自动分级判定 → AI 复核误报 → 导出报告

单文件 exe，免环境依赖，双击即用。

## ✨ 特性

- **🧲 多账号流量录制** — 基于 CDP 无侵入录制，每账号一个独立浏览器实例（窗口带编号标识），Cookie/Token/请求体全量捕获
- **🕸 自动遍历引擎** — 自动收集页面路由（Vue Router/菜单链接）逐个导航，并从已知 API 前缀枚举常见子端点，把"人工点功能点"变成"工具自动扫全站"
- **⚔️ 六重测试引擎**
  | # | 测试 | 检测目标 |
  |---|------|---------|
  | 1 | baseline 原样重放 | 录制有效性 / 防重放机制检测 |
  | 2 | cross 换凭证重放 | 服务端不校验凭证归属（水平/垂直越权）|
  | 3 | noauth 去凭证重放 | 未授权访问 |
  | 4 | param_swap ID交叉 | 对 ID 参数无归属校权（A的凭证+B的ID=B的数据，铁证级证据）|
  | 5 | 深度验证·请求头变体 | 部分系统信任 XFF 头做访问控制的复核 |
  | 6 | 深度验证·方法翻转 | 同一 URL 不同 HTTP Method 鉴权不一致复核 |
- **🤖 AI 误报筛查** — 对全部疑似项自动组装上下文交由 LLM 判定（真漏洞/误报/需人工），支持任何 OpenAI 兼容接口，可一键拉取可用模型列表
- **📊 报告导出** — HTML 报告含数据包左右对照（左请求/右响应，原始 vs 重放）、漏洞描述、复现步骤、影响说明
- **🔀 上游代理** — 全部重放流量可经 Burp Suite 等抓包代理，便于留档复核
- **🛡️ 安全默认值** — 删除类操作自动跳过、认证类接口自动排除、写操作可一键限制为只读（GET）

## 🚀 快速开始

### exe 版（推荐）

1. 下载 `越权测试工具.exe`（约 13 MB）
2. 双击运行，自动弹出控制台页面
3. 要求：Windows 系统 + Chrome 或 Edge 浏览器（Win10/11 自带 Edge 即可）

### 源码版

```bash
pip install websocket-client requests pillow
python idor_pro.py
# 浏览器打开 http://127.0.0.1:8777
```

### 五分钟上手

1. **添加账号** — 至少 2 个（建议 1 个高权限 + 1~2 个低权限，同时覆盖水平/垂直越权）
2. **开启测试** — 每个账号弹出一个独立浏览器窗口（标题带账号编号）
3. **登录** — 各窗口分别登录（验证码人工输入）
4. **自动遍历**（推荐）— 点击「自动遍历全部账号」，工具自动发现并请求全站接口；也可手动浏览功能点，或两者结合
5. **开始越权测试** — 实时查看分级结果
6. **AI 筛查**（可选）— 配置 LLM 接口后一键复核全部疑似项
7. **导出报告**

## 🔍 工作原理

```
账号A浏览器 ──┐                        ┌─> baseline(原凭证原样重放)
账号B浏览器 ──┼─ CDP录制 → 录制池 → 生成测试任务 ─┼─> cross(换B的凭证重放A的请求)
账号C浏览器 ──┘                        ├─> noauth(去掉全部凭证)
                                       ├─> param_swap(A凭证+B的ID参数)
                                       └─> 深度验证(头部变体/方法翻转)
                                              │
                                       判定引擎(五层降噪)
                                              │
                                       🔴高危/🟡中危/🟢正常/⚪公共
                                              │
                                    人工复核 + AI筛查 → HTML报告
```

**五层降噪**（降低误报）：

1. JSON 归一化时忽略时间戳/流水号字段
2. 公共接口识别（双方账号本来都能访问的相同请求）
3. "按凭证身份返回"识别（响应与凭证本人原始响应一致 → 正常行为）
4. 公开接口识别（无敏感数据 → 不报未授权）
5. 认证类接口自动排除（登录/注册/验证码等）

## 🏷 判定分级

| 级别 | 含义 |
|------|------|
| 🔴 高危 | 疑似水平/垂直越权、未授权访问、ID 无归属校验 — 附漏洞描述+复现步骤+影响说明 |
| 🟡 中危 | 管理类接口低权限可访问、公共接口返回敏感字段、需人工确认项 |
| 🟢 正常 | 服务端正确拒绝（401/403/业务码拒绝） |
| ⚪ 公共 | 业务公开数据，自动降噪 |
| 🚫 WAF | 被防护设备拦截，建议人工换方式复核 |
| ⏭️ 跳过 | 删除类操作（默认策略）/ 认证类接口 / 只读模式下的写请求 |

## ⚙️ 测试设置

| 设置 | 默认 | 说明 |
|------|------|------|
| 跳过删除类操作 | ✅ | DELETE 方法或 URL 含 delete/remove 等语义的请求不重放 |
| 包含去凭证测试 | ✅ | 未授权访问检测 |
| 深度验证 | ✅ | 对"防护正常"的接口做头部/方法变体复核 |
| 仅测试 GET | ❌ | 保守模式，POST/PUT 全部跳过 |
| 并发 | 4 | 有 WAF/风控的系统建议 1-2 |
| 上游代理 | 空 | 如 `http://127.0.0.1:8080`（Burp），开跑前自动预检连通性 |
